SUNSET RUN — MOBILE / TABLET

This version is optimized for iPhone, iPad, and touch-screen devices.

IMPORTANT: Because the game uses ES modules, do not open index.html with file://.
Host this folder on an HTTPS web host (or use localhost) and open the resulting URL on the phone/tablet.

For iPhone/iPad: open the HTTPS URL in Safari, tap Share, then Add to Home Screen.
The game supports touch steering, Nitro, Brake, safe-area insets, portrait/landscape UI, and mobile viewport resizing.
